# Поиск по-русски: выбор библиотеки

> Отчёт создан командой `npm run search:compare`. Не правьте его руками — перезапустите сравнение.

Сравнение на 50 контрольных запросах из `src/lib/search/control-queries.ts` (ТЗ, раздел «Поиск»). Индекс — 440 документов: все темы каталога по названиям, модулям и разделам, термины глоссария и блоки темы-образца. Попадание — верный ответ среди первых 3 результатов своей группы; группы идут в порядке «темы, термины, блоки». Порог из критериев приёмки — 90%.

Оговорка: запросы составлены по требованиям ТЗ (формы слов, синонимы, опечатки, английские названия, сокращения), а настройки MiniSearch подбирались на них же. Поэтому в волне 1 набор пополнится запросами по написанным темам, и автотест поиска будет проверять уже его.
