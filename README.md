# «Инвариант»

Бесплатное открытое веб-приложение для глубокого изучения алгоритмов и структур данных, баз данных и SQL, C и C++, Python и математики для информатики, с треком подготовки к собеседованиям. Справочник, тренажёры с генераторами заданий, визуализации, запуск кода и интервальное повторение — в одном месте, на русском языке.

Цель — чтобы человек умел объяснить, доказать, написать код сам, измерить его и помнить это через месяцы.

## Состояние

Идёт первая волна: ядро приложения и 59 тем, от основ JavaScript до сортировок. Этап 0 «Подготовка» — каркас сайта, автопроверки, публикация и прототипы рискованных частей — принят. Сайт: [xyelll228.github.io/Invariant](https://xyelll228.github.io/Invariant/).

## Как идёт работа

Каждая правка — отдельный pull request. Автопроверки запускаются на каждой правке, а у каждой правки есть превью — её можно открыть на компьютере и на телефоне до слияния.
