Основа дизайна

Строгий монохром, крупный текст и одно главное действие на экране. Цвет есть только в визуализациях, и он всегда дублируется формой или подписью.

Переключите тему кнопкой в шапке и проверьте страницу в светлой и тёмной теме.

Шрифты

Текст набран шрифтом Inter, код — Source Code Pro. Оба под свободной лицензией OFL и содержат полную кириллицу, включая казахские буквы: Ә ә, Ғ ғ, Қ қ, Ң ң, Ө ө, Ұ ұ, Ү ү, Һ һ, І і.

Заголовок третьего уровня

Обычный абзац: короткие предложения, строка 60–75 знаков, базовый размер текста не меньше 16 пикселей. Ссылка выглядит так, важное выделяется жирностью, а код в строке — insertionSort(a). Клавиши: ← и →.

Приглушённый текст — для пояснений и подписей.

Код

function swap(a, i, j) {
  const t = a[i];
  a[i] = a[j];
  a[j] = t;
}
