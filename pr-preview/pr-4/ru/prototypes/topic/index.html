Сортировка вставками

Сортировка вставками берёт элементы массива по одному и вставляет каждый на своё место в уже упорядоченную левую часть.

Фундамент

Идея

Так раскладывают карты в руке. Берут следующую карту и вставляют её среди уже разложенных: большие карты сдвигаются вправо, и новая встаёт на своё место.

В массиве всё так же. Слева — упорядоченная часть, справа — элементы, до которых очередь ещё не дошла. Вначале в левой части один элемент, с индексом 0. На каждом шаге первый элемент правой части вставляется в левую: пока сосед слева больше него, их меняют местами.

Разбор на примере

Отсортируем массив из пяти чисел. На каждом шаге видно, какой элемент вставляется, сколько было сравнений и обменов и каким стал массив.

Исходный массив: [7, 3, 5, 1, 4].

Частые ошибки

  • После k шагов упорядочены первые k + 1 элементов, а не k: элемент с индексом 0 стоит в левой части с самого начала.
  • Сортировка вставками не ищет минимум в правой части. Так работает сортировка выбором.

База

Определение

Сортировка вставками упорядочивает массив a длины n по возрастанию. Для каждого i от 1 до n − 1 элемент a[i] вставляется в упорядоченную часть a[0..i − 1]: пока он меньше соседа слева, их меняют местами.

Почему это работает

Перед вставкой элемента с индексом i левая часть a[0..i − 1] упорядочена. Вставка сохраняет это свойство для части a[0..i]. После последнего шага упорядочен весь массив.

Частые ошибки

  • Сравнение a[j − 1] > a[j] нельзя заменять на a[j − 1] >= a[j]: тогда равные элементы меняются местами и сортировка перестаёт быть устойчивой.

Глубина

Обмены и инверсии

Каждый обмен соседей a[j − 1] > a[j] устраняет ровно одну инверсию и не создаёт новых. В конце инверсий не остаётся. Поэтому число обменов равно числу инверсий исходного массива.

Инвариант

Перед вставкой элемента с индексом i в ячейках a[0..i − 1] лежат те же элементы, что и вначале, только упорядоченные. Вставка не трогает ячейки правее i, а внутренний цикл останавливается, когда слева стоит не больший элемент или достигнуто начало массива.

Частые ошибки

  • Число обменов зависит не только от длины массива, но и от порядка элементов: на упорядоченном массиве обменов нет вовсе.

Код

Версии на C++ и Python проверяются при сборке на тех же данных, что и эталон на JavaScript.

JavaScript

function insertionSort(a) {
  for (let i = 1; i < a.length; i++) {
    let j = i;
    while (j > 0 && a[j - 1] > a[j]) {
      [a[j - 1], a[j]] = [a[j], a[j - 1]];
      j--;
    }
  }
  return a;
}

C++

#include <cstddef>
#include <utility>
#include <vector>

// Сортировка вставками обменами: тот же алгоритм, что и эталон на JavaScript.
void insertion_sort(std::vector<long long>& a) {
    for (std::size_t i = 1; i < a.size(); ++i) {
        for (std::size_t j = i; j > 0 && a[j - 1] > a[j]; --j) {
            std::swap(a[j - 1], a[j]);
        }
    }
}

Python

def insertion_sort(a: list[int]) -> list[int]:
    """Сортировка вставками обменами: тот же алгоритм, что и эталон на JavaScript."""
    for i in range(1, len(a)):
        j = i
        while j > 0 and a[j - 1] > a[j]:
            a[j - 1], a[j] = a[j], a[j - 1]
            j -= 1
    return a

Термины

устойчивая сортировка (stable sort)
Сортировка, которая сохраняет взаимный порядок элементов с равными ключами: если элемент x стоял раньше элемента y и ключи у них равны, после сортировки x по-прежнему стоит раньше y.
сортировка на месте (in-place sort)
Сортировка, при которой элементы переставляются внутри самого массива, а вне его одновременно хранится лишь постоянное число элементов.
инверсия (inversion)
Пара индексов i < j, для которой a[i] > a[j]: два элемента стоят в неправильном относительном порядке. В упорядоченном по возрастанию массиве инверсий нет.
