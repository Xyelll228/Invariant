О проекте

«Инвариант» — бесплатное открытое приложение для учёбы: справочник, тренажёры, визуализации, запуск кода и интервальное повторение.

Данные и приватность

  • Регистрации нет. Всё, что вы делаете в приложении, хранится только в вашем браузере.
  • Аналитики, рекламы и сторонних скриптов нет.
  • Сайт размещён на GitHub Pages. GitHub сам записывает IP-адреса посетителей в целях безопасности — так работает хостинг.

Лицензии

  • Код — MIT.
  • Учебный контент — CC BY-SA 4.0.
  • Тексты пишем сами, опираясь на открытые учебники с совместимыми лицензиями; у каждой темы будет список источников.

Как сообщить об ошибке

Откройте задачу (issue) в репозитории на GitHub. Кнопка «Нашёл ошибку» с уже заполненной формой появится вместе с первыми темами. Контакт для тех, у кого нет аккаунта GitHub, появится здесь до выхода первой волны.

Исходный код
