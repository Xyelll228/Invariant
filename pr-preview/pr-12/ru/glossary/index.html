Глоссарий

Термины, которыми пользуются темы. Здесь же закреплены спорные соглашения: например, что массивы нумеруются с нуля. Терминов: 3.

Тренажёр терминов — в конце страницы.

  • И
  • С
  • У

И

Инверсия inversion

Пара индексов i < j, для которой a[i] > a[j]: два элемента стоят в неправильном относительном порядке. В упорядоченном по возрастанию массиве инверсий нет.

Пример: В массиве [3, 1, 2] две инверсии — пары значений (3, 1) и (3, 2).

Тема: Сортировка вставками

С

Сортировка на месте in-place sort

Сортировка, при которой элементы переставляются внутри самого массива, а вне его одновременно хранится лишь постоянное число элементов.

Пример: Сортировка вставками работает на месте, а сортировка слиянием с отдельным буфером — нет.

Тема: Сортировка вставками

Часто путают с: устойчивая сортировка

У

Устойчивая сортировка stable sort

Сортировка, которая сохраняет взаимный порядок элементов с равными ключами: если элемент x стоял раньше элемента y и ключи у них равны, после сортировки x по-прежнему стоит раньше y.

Пример: Список студентов, упорядоченный по фамилии, сортируют по номеру группы. Устойчивая сортировка оставит студентов внутри каждой группы в алфавитном порядке.

Другие варианты: стабильная сортировка.

Тема: Сортировка вставками

Часто путают с: сортировка на месте
