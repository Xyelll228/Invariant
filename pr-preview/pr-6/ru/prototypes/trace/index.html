След алгоритма

Эталон сортировки вставками записывает след: сравнения, обмены и текущие строки кода. Из одного следа строятся анимация, ручная симуляция, разбор по шагам, задания и счётчики операций.

Одна реализация вместо пяти — меньше мест, где может спрятаться ошибка, и всё согласовано между собой. Код эталона проверяется автотестами: свойства на случайных данных, мутанты и эксперимент удвоения.

Визуализация

Шаги вперёд и назад, автопроигрывание, описание каждого шага и таблица состояний вместо анимации. В режиме «Предсказывать» перед шагом приложение спрашивает, что произойдёт. Можно ввести свои данные.

Ручная симуляция

Выполните сортировку сами. Каждый шаг сверяется со следом эталона: при ошибке видно правильный шаг и причину, а шаг можно повторить.

Выполните алгоритм сами: нажмите на два элемента, которые нужно поменять местами следующими. Выбор снимается повторным нажатием.

Исходный массив: [7, 3, 5, 1, 4].

Задание генератора

Условие и варианты строит генератор: правильный ответ вычисляет эталон, неверные — «неправильные алгоритмы», каждый со своим заблуждением. Номер варианта воспроизводит задание точно.
