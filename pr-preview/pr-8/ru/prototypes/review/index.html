Хранилище, повторение и экспорт

Прогресс хранится только в вашем браузере. Ответ превращается в оценку по правилам, а следующее повторение планирует FSRS. Копия в файл переносит прогресс на другое устройство.

Карточка — это навык, а не вопрос: при каждом повторении генератор даёт новый вариант. Оценку ставит приложение по результату и уверенности: «наугад» даже при верном ответе — Again, «сомневаюсь» — Hard, «знаю» — Good, а после подсказки — не выше Hard.
