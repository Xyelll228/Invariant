Инвариант

Открытое приложение для глубокого изучения алгоритмов и структур данных, баз данных и SQL, C и C++, Python и математики для информатики — с треком подготовки к собеседованиям.

Цель — чтобы вы умели объяснить, доказать, написать код сам, измерить его и помнили это через месяцы, а не узнавали правильный ответ среди вариантов.

С чего начать

  • Если программируете впервые — с раздела «Основы JavaScript»: на нём написаны все упражнения.
  • Если основы знаете — с любого модуля, например с «Сортировок». Предпосылки каждой темы видны в её шапке.

Разделы

  • 0. Основы JavaScript для упражнений

    Упражнения написаны на JavaScript, поэтому человеку без опыта нужен короткий вход: 21 тема, только уровни Фундамент и База.

  • 1. Алгоритмы и структуры данных

    150 тем в 15 модулях. Модуль «Сортировки» целиком идёт в первую волну: на нём проверяется весь процесс производства контента.

  • 2. Базы данных и SQL

    75 тем в 13 модулях. Запросы выполняются в песочнице на SQLite, а там, где SQLite тему не показывает, — на PostgreSQL (PGlite). Где MySQL ведёт себя иначе, это отмечено в тексте темы.

  • 3. C и C++

    59 тем в 8 модулях. Пока код на C и C++ не запускается в браузере: он проверяется автоматически при сборке, а в заданиях его читают, трассируют и ищут в нём ошибки. Запуск в браузере исследуем в волне 4 и решим по результату.

  • 4. Python

    37 тем в 4 модулях. В этом разделе свой код на Python запускается прямо в браузере через Pyodide — с волны 4, вместе с разделом. Вкладки Python в темах алгоритмов проверяются при сборке.

  • 5. Математика для информатики

    46 тем в 9 модулях. Математику не откладываем до конца: темы, нужные для анализа алгоритмов, выходят вместе с ними — логарифмы уже в первой волне.

  • 6. Подготовка к собеседованиям

    39 тем в 4 модулях. Условия задач пишем сами; на внешние площадки вроде LeetCode ставим только ссылки и их условия не копируем.
