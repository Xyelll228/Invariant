Сортировка вставками

Сортировка вставками берёт элементы массива по одному и вставляет каждый на своё место в уже упорядоченную левую часть.

Определение и псевдокод

Сортировка вставками упорядочивает массив a длины n по неубыванию: каждый следующий элемент не меньше предыдущего. Для каждого i от 1 до n − 1 элемент a[i] вставляется в упорядоченную часть a[0..i − 1]. Вставка — это обмены с соседом слева, пока он строго больше.

Псевдокод:

  1. Для i от 1 до n − 1:
    1. j ← i.
    2. Пока j > 0 и a[j − 1] > a[j]:
      1. поменять местами a[j − 1] и a[j];
      2. j ← j − 1.

Сравнение строгое. Равные элементы не меняются местами, поэтому их порядок сохраняется: сортировка устойчивая. Все перестановки делаются внутри массива. Кроме него нужны только переменные i и j и место для одного элемента при обмене, поэтому это сортировка на месте.

function insertionSort(a) {
  for (let i = 1; i < a.length; i++) {
    let j = i;
    while (j > 0 && a[j - 1] > a[j]) {
      [a[j - 1], a[j]] = [a[j], a[j - 1]];
      j--;
    }
  }
  return a;
}

// Сортировка вставками обменами: тот же алгоритм, что и эталон на JavaScript.
void insertion_sort(std::vector<long long>& a) {
    for (std::size_t i = 1; i < a.size(); ++i) {
        for (std::size_t j = i; j > 0 && a[j - 1] > a[j]; --j) {
            std::swap(a[j - 1], a[j]);
        }
    }
}

def insertion_sort(a: list[int]) -> list[int]:
    """Сортировка вставками обменами: тот же алгоритм, что и эталон на JavaScript."""
    for i in range(1, len(a)):
        j = i
        while j > 0 and a[j - 1] > a[j]:
            a[j - 1], a[j] = a[j], a[j - 1]
            j -= 1
    return a

Сложность и свойства

Сравнением будем считать проверку a[j − 1] > a[j]. Проверка j > 0 сравнивает индексы, а не элементы, и в счёт не идёт.

Лучший случай — массив уже упорядочен. Для каждого i первое же сравнение показывает, что сосед слева не больше, и вставка заканчивается. Всего n − 1 сравнений и ни одного обмена: время Θ(n).

Худший случай — различные элементы упорядочены по убыванию. Элемент с индексом i меньше всех элементов левее и доходит до начала: i сравнений и i обменов. Всего сравнений

1+2+⋯+(n−1)=n(n−1)2,1 + 2 + \dots + (n - 1) = \frac{n(n-1)}{2},

обменов столько же. Время Θ(n²).

Средний случай — случайная перестановка различных чисел. В среднем элемент с индексом i меньше половины элементов левее, и обменов при его вставке в среднем i/2. Всего

12+22+⋯+n−12=n(n−1)4\frac{1}{2} + \frac{2}{2} + \dots + \frac{n-1}{2} = \frac{n(n-1)}{4}

обменов — вдвое меньше, чем в худшем случае, но это по-прежнему Θ(n²).

Дополнительная память — O(1) во всех случаях. Сортировка устойчивая и работает на месте. Ещё она адаптивная: чем ближе массив к упорядоченному, тем меньше работы.

Почему это работает: идея

показать доказательство

Доказательство держится на инварианте цикла: перед итерацией с индексом i часть a[0..i − 1] упорядочена.

  • До первой итерации, при i = 1, в этой части один элемент — она упорядочена.
  • Итерация вставляет a[i]: он сдвигается влево, пока сосед слева больше. Когда сдвиг остановился, слева от вставленного элемента стоит не больший элемент или начало массива, а справа — большие элементы. Часть a[0..i] упорядочена.
  • Цикл заканчивается при i = n. Тогда по инварианту упорядочена часть a[0..n − 1], то есть весь массив.

Полное доказательство — на уровне «Глубина».

Частые ошибки

  • Сравнение a[j − 1] > a[j] заменяют на a[j − 1] >= a[j]. Массив по-прежнему упорядочится, но равные элементы будут меняться местами: сортировка потеряет устойчивость.
  • Условие j > 0 заменяют на j > 1. Тогда элемент не может дойти до индекса 0, и наименьший элемент может остаться не на месте.
  • Цикл while заменяют на if или забывают j–. Тогда элемент сдвигается не больше чем на одну позицию.
  • Внешний цикл начинают с i = 2 или заканчивают на i < n − 1. Тогда второй или последний элемент может остаться не на своём месте.
  • Считают, что сортировка вставками всегда квадратична. На упорядоченном массиве она делает n − 1 сравнений.

Ваша заметка

Вставки или выбор: операции

  • Сравнения. Сортировка выбором на любых данных просматривает всю правую часть, чтобы найти наименьший элемент. Вставкам на упорядоченном массиве хватает n − 1 сравнений, а в среднем они делают примерно вдвое меньше сравнений, чем выбор.
  • Записи в массив. Вставки в худшем случае делают Θ(n²) обменов. Выбор делает не больше одного обмена за шаг, всего O(n).

Поэтому на почти упорядоченных данных выгоднее вставки, а когда запись в память намного дороже чтения — выбор.

Термины

массив (array)
Последовательность элементов, у каждого из которых есть номер — индекс. Элемент можно прочитать или заменить по его индексу.
индекс (index)
Номер элемента в массиве. В «Инварианте» индексы считаются с нуля: у первого элемента индекс 0, у последнего в массиве длины n — индекс n − 1.
устойчивая сортировка (stable sort)
Сортировка, которая сохраняет взаимный порядок элементов с равными ключами: если элемент x стоял раньше элемента y и ключи у них равны, после сортировки x по-прежнему стоит раньше y.
сортировка на месте (in-place sort)
Сортировка, при которой элементы переставляются внутри самого массива, а вне его одновременно хранится лишь постоянное число элементов.
инвариант цикла (loop invariant)
Утверждение, которое верно каждый раз перед проверкой условия цикла: до первой итерации, после каждой итерации и поэтому при выходе из цикла. Через инвариант доказывают, что цикл делает то, что нужно.
лучший случай (best case)
Входные данные размера n, на которых алгоритм делает меньше всего операций, и само это наименьшее число операций.
худший случай (worst case)
Входные данные размера n, на которых алгоритм делает больше всего операций, и само это наибольшее число операций.
средний случай (average case)
Среднее число операций по всем входным данным размера n. Обычно считают, что все перестановки входа равновероятны; другое распределение называют явно.
O-большое (big O)
Запись f(n) = O(g(n)) значит: есть постоянная c > 0, что f(n) ≤ c · g(n) при всех достаточно больших n. Это оценка сверху с точностью до постоянного множителя.
Θ-большое (big Theta)
Запись f(n) = Θ(g(n)) значит: есть постоянные c₁, c₂ > 0, что c₁ · g(n) ≤ f(n) ≤ c₂ · g(n) при всех достаточно больших n. Это точная оценка роста — и сверху, и снизу.
адаптивная сортировка (adaptive sort)
Сортировка, которая работает быстрее на почти упорядоченных данных: число её операций зависит от того, насколько беспорядочен вход, а не только от его длины.
инверсия (inversion)
Пара индексов i < j, для которой a[i] > a[j]: два элемента стоят в неправильном относительном порядке. В упорядоченном по возрастанию массиве инверсий нет.
онлайн-алгоритм (online algorithm)
Алгоритм, который обрабатывает данные по мере поступления и не ждёт, пока придёт весь вход.
бинарный поиск (binary search)
Поиск в упорядоченном массиве: на каждом шаге искомое значение сравнивается с элементом в середине отрезка, и половина отрезка, где искомого быть не может, отбрасывается.
